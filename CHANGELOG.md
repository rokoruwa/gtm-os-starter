## [0.1.0] - 2026-11-01

### Added

- `foundation/` filled in for Northwind Rentals, a fictional company, with 25 invented accounts.
- Eight skills in flat `.claude/skills/` folders: icp-fit, positioning, angle-finder, linkedin-post, founder-email, pre-publish-gate, scorecard and post-performance.
- One worked example per skill in `examples/`.
- Deny rules in `.claude/settings.json` for send, publish, schedule, delete and CRM-write tools.
- Four validators run with `bun test`.
- CI for tests and a gitleaks secret scan.
