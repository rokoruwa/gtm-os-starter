# Metrics

**Load this file when:** reporting results, building a scorecard, or deciding whether a number can appear in public copy.

**Fictional.** These definitions belong to Northwind Rentals, an invented company.

## The rule

A metric appears in a report or in public copy only with its source next to it. No source, the value reads TBD. A skill never estimates, rounds up or fills a gap.

## Adding a metric

Add a row with all five columns filled. Leave "Current value" as TBD until a report you can link to supplies it. A metric without a source column doesn't go in this table.
